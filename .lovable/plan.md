

# Portfolio Website for Ashish Kumar

A modern, dark-themed portfolio website with blue/black gradients and a futuristic tech aesthetic.

---

## Design Direction
- **Theme**: Dark background (near-black) with electric blue gradient accents
- **Typography**: Clean sans-serif (Inter) for a modern, professional feel
- **Style**: Minimalistic with subtle tech patterns, smooth hover effects, and fade-in scroll animations
- **Fully responsive** across mobile, tablet, and desktop
